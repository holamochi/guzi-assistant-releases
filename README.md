# 谷子助手旧版更新源（已归档）

**谷子助手已开源，源码、安装包和后续更新都在 [holamochi/Guzi-Assistant](https://github.com/holamochi/Guzi-Assistant)。** 本仓库已归档，不再发布新版本。

| 你的情况 | 怎么做 |
| --- | --- |
| 第一次安装 | 到 [官网](https://a.guzilab.com/) 或 [Guzi-Assistant Releases](https://github.com/holamochi/Guzi-Assistant/releases/latest) 下载 |
| 已安装 v0.13.0 或 v0.14.0 | 在「设置 → 关于」里点「检查更新」，升级到 v0.15.0；之后会自动从新仓库获取更新 |
| 已安装 v0.15.0 及以上 | 不用做任何事 |

## 为什么还保留这个仓库

v0.13.0 和 v0.14.0 的安装包会到这里检查更新，所以本仓库保留：

- v0.13.0、v0.14.0 的历史安装包；
- 引导旧版本升级的更新源，也就是 v0.15.0 迁移发布。

**请勿删除本仓库**，否则尚未升级的旧版本将收不到更新。
